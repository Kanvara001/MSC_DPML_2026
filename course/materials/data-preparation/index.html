Using the decks

The same controls work in every chapter.

Present

  • ← → Space move between slides
  • O opens the grid of every slide
  • F fullscreen, T starts the lecture timer
  • Type a number then Enter to jump

Edit and annotate

  • E turns on edit mode — click any heading, bullet, table cell, caption or reference and rewrite it
  • N opens speaker notes, with the next slide title above them
  • Everything autosaves to this browser

Take it away

  • Export → Markdown for a handout or your lecture prep
  • Export → JSON backup to carry edits to another machine
  • P prints one slide per page with your notes underneath

Find something

  • / searches every slide, reference and note in the open deck
  • Section names appear in the toolbar and in the slide grid
  • ? shows the full key list

On the figures. Every diagram in these decks was drawn for this course as inline vector graphics — nothing is copied from a published paper, so the decks can be shared, printed and adapted freely. Illustrative charts are labelled as such; where a figure carries real numbers, the source is named in its caption.

On the citations. Sources appear as numbered footnotes on the slide that cites them, with a superscript marker at the mention, and again in full on each section's reference slide. Every footnote is derived from those reference lists, so nothing is invented — where a first author has more than one work in the course, the footnote is only shown when the year in the text identifies which one is meant. Work from the Visual Intelligence Laboratory is cited in the same form as everything else and marked in the slide kicker.

Keep a backup. Edits live in this browser's storage. Before reinstalling, changing machine or clearing site data, use Export → JSON backup in each deck.
