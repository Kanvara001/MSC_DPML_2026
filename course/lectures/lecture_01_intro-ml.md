## 2. Machine Learning

**Machine Learning (ML)** คือการสอนให้คอมพิวเตอร์เรียนรู้จากข้อมูล เปรียบเหมือนการติวสอบ คือมี **โจทย์** และ **เฉลย** ให้ดูว่าทำอย่างไร เมื่อเจอโจทย์ใหม่ก็ควรทำได้ (รูปแบบนี้เรียกว่า **Supervised Learning** ซึ่งเป็นแบบที่ใช้ในคาบนี้)

ข้อสรุปที่ตามมา
- ต้องมี **ข้อมูลจำนวนมาก** โมเดลจึงทำงานได้ดี
- คอมพิวเตอร์ต้อง **ประมวลผลได้เร็ว** การฝึกโมเดลขนาดใหญ่จึงทำได้จริง
- AI สมัยใหม่ส่วนใหญ่ใช้ ML เป็นพื้นฐานในการเรียนรู้
- **Deep Learning** ได้รับความสนใจอย่างมากในช่วงปี **2012** เมื่อโมเดล AlexNet ชนะการแข่งขัน ImageNet ด้วยความแม่นยำสูงกว่าวิธีเดิมอย่างชัดเจน

### 2.1 โมเดลเรียนรู้จากความผิดพลาดอย่างไร

ระหว่างฝึก โมเดลจะทำนายคำตอบแล้วเทียบกับเฉลย ยิ่งทำนายผิดมาก ค่าความผิดพลาด (**Loss**) ก็ยิ่งสูง การเรียนรู้คือการปรับโมเดลให้ Loss ลดลง

> คำว่า Reward / Penalty (รางวัลและโทษ) เป็นศัพท์ของ **Reinforcement Learning** ซึ่งเรียนรู้จากการลองทำและได้รับผลตอบรับ ต่างจาก Supervised Learning ที่เรียนรู้จากเฉลยโดยตรง

### 2.2 ML กับ Deep Learning ต่างกันอย่างไร

Deep Learning เป็น **ส่วนหนึ่งของ** Machine Learning (ใช้ Neural Network หลายชั้น) ความแตกต่างหลักอยู่ที่เรื่อง feature

| | ML แบบดั้งเดิม | Deep Learning |
|---|---|---|
| Feature | มนุษย์ต้องออกแบบและเลือก feature เอง (**Feature Engineering**) | โมเดลเรียนรู้ feature จากข้อมูลดิบเอง จึงลดงาน Feature Engineering ลงมาก |

### 2.3 ฮาร์ดแวร์: CPU และ GPU

- **CPU**: ประมวลผลงานทั่วไป มี core จำนวนน้อยแต่แต่ละ core ทำงานซับซ้อนได้
- **Core** คือหน่วยประมวลผลที่ทำงานได้พร้อมกัน จำนวน core มากแปลว่าทำงานแบบขนานได้มาก
- **GPU (การ์ดจอ)**: มี core ที่ทำงานง่ายกว่าแต่มีจำนวนมาก (หลักพันถึงหลักหมื่น) เหมาะกับการคำนวณเมทริกซ์แบบขนาน ซึ่งเป็นหัวใจของการประมวลผลภาพและการฝึก Neural Network จึงใช้ GPU เร่งการฝึก ML ได้

## 3. ข้อมูลและโมเดล

ข้อมูลสำหรับ Supervised Learning แบ่งเป็น 2 ส่วน คือ **โจทย์ (Observation / Input)** และ **คำตอบ (Label / Target)**

**โมเดล** คือฟังก์ชันที่ map จากโจทย์ไปยังคำตอบ โดยโมเดลจะ **เรียนรู้ฟังก์ชันนั้นจากข้อมูล** (ฟังก์ชันที่ได้อยู่ในรูปแบบที่โมเดลแต่ละชนิดกำหนด เช่น เส้นตรง ต้นไม้ตัดสินใจ หรือ Neural Network)

### 3.1 โครงสร้างข้อมูล

| คำศัพท์ | ความหมาย |
|---|---|
| Row (Data point / Sample) | ข้อมูลหนึ่งจุด หรือหนึ่งตัวอย่าง (ถ้ามี 4 row คือมีข้อมูล 4 จุด) |
| Attribute (Feature) | คอลัมน์ที่อธิบายข้อมูล ถ้าข้อมูลสองจุดมี feature เหมือนกันทุกตัว จะถูกวางที่ตำแหน่งเดียวกันใน Feature Space และโมเดลจะแยกไม่ออก |
| **X** | ข้อมูลนำเข้า (Feature) |
| **Y** | คำตอบ (Label / Target) |
| Feature Space | ปริภูมิที่ข้อมูลแต่ละจุดถูกวางตามค่า feature |

### 3.2 Regression

**Regression** ใช้ทำนายค่าที่เป็นตัวเลขต่อเนื่อง (เช่น ราคา อุณหภูมิ) เส้น regression ต้องเป็นเส้นที่ **ประมาณค่าของจุดข้อมูลได้ดี** คือทำให้ความคลาดเคลื่อนระหว่างเส้นกับจุดข้อมูลน้อยที่สุด (เช่นวิธี Least Squares) เมื่อมีข้อมูลใหม่เข้ามา ก็ลากเส้นขึ้นไปอ่านค่าที่ทำนายได้ เส้นนี้อาจเป็นเส้นตรงหรือเส้นโค้งก็ได้

### 3.3 Classification

**Classification** ใช้ทำนายว่าข้อมูลอยู่ใน **กลุ่ม (class)** ใด โมเดลจะเรียนรู้ **เส้นแบ่ง (Decision Boundary)** ใน feature space เมื่อมีข้อมูลใหม่เข้ามา ข้อมูลจะถูกวางลงใน feature space และถูกจัดเข้ากลุ่มตามฝั่งของเส้นแบ่งที่ตกอยู่ ซึ่งโดยสัญชาตญาณคือใกล้กลุ่มที่คล้ายกันมากกว่า

เส้นแบ่งขึ้นอยู่กับข้อมูลที่ใช้ฝึก ถ้าข้อมูลบางจุด (โดยเฉพาะจุดที่อยู่ใกล้เส้นแบ่ง) หายไป เส้นแบ่งก็เปลี่ยนไปได้

### 3.4 Variability

**Variability** คือความหลากหลายของข้อมูล เราต้องมีข้อมูลหลายแบบให้โมเดลได้เรียนรู้ เพื่อให้โมเดลทำงานกับข้อมูลใหม่ที่ไม่เคยเห็นได้ดี (Generalization)

### 3.5 ประเภทของโมเดล

- **Discriminative Model**: เรียนรู้ความแตกต่างระหว่างกลุ่มข้อมูล เพื่อแบ่งว่าข้อมูลอยู่ class ไหน
- **Generative Model**: เรียนรู้การกระจายของข้อมูล เพื่อสร้างข้อมูลใหม่
