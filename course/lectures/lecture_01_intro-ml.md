## 2. Machine Learning

**Machine Learning (ML)** คือการสอนให้คอมพิวเตอร์เรียนรู้ เปรียบเหมือนการติวสอบ คือมี **โจทย์** และ **เฉลย** ให้ดูว่าทำอย่างไร เมื่อเจอโจทย์ใหม่ก็ควรทำได้

ข้อสรุปที่ตามมา
- ต้องมี **ข้อมูลจำนวนมาก** โมเดลจึงทำงานได้ดี
- คอมพิวเตอร์ต้อง **ประมวลผลได้เร็ว** งานจึงสำเร็จ
- AI เริ่มได้รับความสนใจอย่างมากในช่วงปี **2012**
- AI ส่วนใหญ่ (ประมาณ 99.99%) ใช้ ML เป็นพื้นฐานในการเรียนรู้
- ระหว่างเรียนรู้ ถ้าโมเดลทำผิด คะแนนจะลดลง (Reward / Penalty)

### 2.1 ML กับ Deep Learning ต่างกันอย่างไร

| | Machine Learning | Deep Learning |
|---|---|---|
| Feature | ต้องออกแบบ feature เอง (Feature Engineering) | ตัดขั้น Feature Engineering ออก โมเดลเรียนรู้ feature เอง |

### 2.2 ฮาร์ดแวร์: CPU และ GPU

- **CPU**: ใช้ประมวลผลและเขียนโปรแกรมทั่วไป
- **Core** คือจำนวนงานที่ทำได้พร้อมกัน
- **GPU (การ์ดจอ)**: มี core จำนวนมาก (หลักหมื่นถึงแสน) เหมาะกับงานภาพ และใช้ประมวลผล ML ได้

## 3. ข้อมูลและโมเดล

การเรียนรู้แบ่งเป็น 2 ส่วน คือ **โจทย์ (Observation)** และ **คำตอบ**

**โมเดล** คือการเรียนรู้ฟังก์ชันหนึ่งฟังก์ชัน (จะเป็นฟังก์ชันอะไรก็ได้) ที่ map จากโจทย์ไปยังคำตอบ

### 3.1 โครงสร้างข้อมูล

| คำศัพท์ | ความหมาย |
|---|---|
| Row | ข้อมูลหนึ่งจุด (ถ้ามี 4 row คือมีข้อมูล 4 จุด) |
| Attribute (Feature) | คอลัมน์ที่อธิบายข้อมูล ถ้าข้อมูลสองจุดมี attribute เหมือนกันทุกตัว ถือว่าเป็นข้อมูลเดียวกัน |
| **X** | ข้อมูลนำเข้า (Feature) |
| **Y** | คำตอบ |
| Feature Space | ปริภูมิที่ข้อมูลแต่ละจุดถูกวางตามค่า feature |

### 3.2 Regression

เส้น regression ต้องเป็นเส้นที่ **ประมาณค่าของจุดข้อมูลได้ดี** เมื่อมีข้อมูลใหม่เข้ามา ก็ลากเส้นขึ้นไปอ่านค่าที่ทำนายได้เลย

### 3.3 Classification

เมื่อมีข้อมูลใหม่เข้ามา ข้อมูลจะถูกวางลงใน feature space แล้ว **เอนเอียงไปทางกลุ่มที่คล้ายกว่า** นอกจากนี้ถ้าข้อมูลบางจุดหายไป เส้นแบ่งก็จะเปลี่ยนไปด้วย

### 3.4 Variability

**Variability** คือความหลากหลายของข้อมูล เราต้องมีข้อมูลหลายแบบให้โมเดลได้เรียนรู้

### 3.5 ประเภทของโมเดล

- **Discriminative Model**: โมเดลที่แบ่งได้ว่าข้อมูลอยู่ class ไหน (แนวคิดค่อนข้างเก่า)
- **Generative Model**: ดูรายละเอียดใน [Lecture 2](lecture_02_llm.md)
