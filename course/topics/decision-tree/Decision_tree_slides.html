Information Gain

ความไม่เป็นระเบียบ “ก่อนถาม” ลบ “หลังถาม” = กำไรที่ได้จากคำถามนั้น

Gain(A)  =  Info(D)  −  InfoA(D)
กฎของ ID3 / C4.5

ที่ทุก node คำนวณ Gain ของ attribute ที่เหลือทุกตัว แล้ว เลือกตัวที่สูงที่สุด

Gain ≥ 0 เสมอ

รู้เพิ่มไม่ทำให้มั่วขึ้น

Gain = 0

ถามแล้วไม่ได้อะไรเลย

Gain = Info(D)

แบ่งครั้งเดียวบริสุทธิ์หมด
