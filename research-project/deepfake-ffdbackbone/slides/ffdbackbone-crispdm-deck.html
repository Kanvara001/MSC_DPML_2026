4 · Modeling · Stage 2 Fine-tuning

Competitive Backbone Framework (CFB)

Decorrelation constraint

Ldec = Pearson(fM, fA)

  • fM, fA คือ [CLS] token ของ main และ auxiliary branch
  • ลด correlation ทำให้ 2 branch เรียนรู้ร่องรอยการปลอมคนละแบบ
  • ใช้ stop-gradient ที่ main branch ทำให้ Ldec ปรับเฉพาะ auxiliary
Uncertainty-based fusion module (UFM)

u = K / S,   wM, wA = softmax(−uM, −uA)

Branch ที่มี uncertainty ต่ำกว่าได้น้ำหนักมากกว่าใน F = wMfM + wAfA

LOSS (EQ. 9) L = LMEDU + LAEDU + LFce + Ldec LEDU = LEDL + LEUC (evidential + calibration)

4 · Modeling · Algorithm ① Pre-training

Masked image modeling: ทาย visual token ของ patch ที่ถูกปิด

models/lib/BEiT_v2/modeling_pretrain.py · VisionTransformerForMaskedImageModeling 
def forward_features(self, x, bool_masked_pos):
    x = self.patch_embed(x)                       # (B,196,768)
    mask_token = self.mask_token.expand(B, 196, -1)
    # replace the masked visual tokens by mask_token
    w = bool_masked_pos.unsqueeze(-1).type_as(mask_token)
    x = x * (1 - w) + mask_token * w
    x = torch.cat((cls_tokens, x), dim=1)        # (B,197,768)
    for blk in self.blocks:                     # 12 block
        x = blk(x, rel_pos_bias=rel_pos_bias)
    return self.norm(x)

def forward(self, x, bool_masked_pos):
    x = self.forward_features(x, bool_masked_pos)[:, 1:]
    return self.lm_head(x[bool_masked_pos])     # Linear(768 → 8192)
ขั้นตอน
  1. แบ่งภาพใบหน้าจริงเป็น 14 × 14 = 196 patch
  2. สุ่ม mask บาง patch แล้วแทนด้วย mask_token ที่เรียนได้
  3. ViT encode ทั้ง 197 token (รวม [CLS])
  4. lm_head ทายรหัส visual token (1 ใน 8,192) ของ patch ที่ถูก mask · เป้าหมายมาจาก tokenizer VQ-KD ของ BEiT v2

CFB forward: 2 backbone, head ร่วมกัน และรวม feature ตาม uncertainty

models/custom.py · DDBF_BEiT_v2.forward (25–42) · โค้ดจริง 
def forward(self, x):
    B, T, C, H, W = x.size()
    x = x.flatten(0,1)
    clstoken  = self.backbone_model(x)          # f_M  main
    clstoken2 = self.backbone_model2(x)         # f_A  auxiliary
    pearson_loss = pearson_correlation_loss(clstoken.detach(), clstoken2)
    pred1 = self.header(self.norm_for_cls(clstoken))
    pred2 = self.header(self.norm_for_cls(clstoken2))
    pred1_un = uncertainty(pred1)
    pred2_un = uncertainty(pred2)
    weight = (-10)*torch.cat([pred1_un,pred2_un], dim=-1)
    w = torch.nn.functional.softmax(weight, dim=-1)
    weighted_output = torch.matmul(w.unsqueeze(1),
        torch.stack((clstoken, clstoken2), dim=1)).squeeze(1)
    pred = self.header(self.norm_for_cls(weighted_output))
    output  = pred.view(B, T, -1)               # fused
    output1 = pred1.view(B, T, -1)              # main
    output2 = pred2.view(B, T, -1)              # auxiliary
    return output, output1, output2, pearson_loss

4 · Modeling · Algorithm ④ Ldec และ uncertainty

Ldec คือค่า Pearson โดยตรง การ minimize จึงดันให้ 2 branch มี correlation ติดลบ

models/custom.py · pearson_correlation_loss (55–68) 
def pearson_correlation_loss(x, y):
    mean_x = torch.mean(x, dim=-1, keepdim=True)  # เฉลี่ยตามมิติ feature
    mean_y = torch.mean(y, dim=-1, keepdim=True)
    xm = x.sub(mean_x);  ym = y.sub(mean_y)
    Conv_xy = torch.bmm(xm.unsqueeze(1),
                        ym.unsqueeze(2)).squeeze()/x.size(-1)
    std_x = torch.std(x, dim=-1);  std_y = torch.std(y, dim=-1)
    pearson_cor = Conv_xy/(std_x*std_y)            # 1 ค่าต่อ 1 ภาพ
    r = torch.clamp(pearson_cor.mean(), -1.0, 1.0)   # เฉลี่ยทั้ง batch
    return r

S = torch.sum(alpha, dim=1, keepdim=True)
A = torch.sum(y * (torch.log(S) - torch.log(alpha)), dim=1)    # L_EDL

pred_scores, pred_cls = torch.max(alpha / S, 1, keepdim=True)

acc_match = (pred_cls == target).float()

avu_loss = λ_t * acc_match * acc_uncertain \

def utom_adjust(p, u, lam=0.02, eps=1e-7):
    return np.tanh(lam * p / (2 * (u + eps)))        # Eq. 10

def best_threshold(y, s):                          # Eq. 11
    o = np.argsort(s)                      # ทุกค่า score เป็นผู้สมัคร τ
    real_below = cumsum(real[o])           # real ที่ s < τ (ถูก)
    fake_above = n_fake − cumsum(fake[o])  # fake ที่ s ≥ τ (ถูก)
    return s[o][argmax(real_below + fake_above)]

6 · Deployment · Reproducibility

ข้อจำกัดด้าน reproducibility ที่พบจากการตรวจบทความ, supplementary และ repository

ประเด็นสิ่งที่ผู้เขียนให้มาผลต่อการทำซ้ำ
Pre-trainingมีแต่ weight สำเร็จรูป ไม่มีสคริปต์, config หรือจำนวน epochใช้ weight ของผู้เขียน
Datasetบอกชื่อและอ้างอิง แต่ไม่มีลิงก์ (ติดเงื่อนไขห้ามแจกต่อ)ต้องขอสิทธิ์หรือหาข้อมูลเอง
FFIWบทความเขียน 10k วิดีโอ แต่ไฟล์ score มี 500 วิดีโอโดยไม่ระบุชื่อเทียบผลได้แบบประมาณเท่านั้น
DFDCP, DFDไม่ระบุ subset และจำนวนที่ใช้ต้องกำหนดเอง
UTOMมีสมการในบทความ แต่ไม่มีโค้ดใน repoต้องเขียนเอง
Ablation, few-shotไม่มีสคริปต์หรือตัวเลือกใน config · few-shot ไม่ระบุวิธีสุ่มและการแยกจากชุดทดสอบต้องแก้โค้ดและกำหนด protocol เอง
โค้ด vs บทความUFM ในโค้ดใช้ softmax(−10·u) ส่วนบทความเขียน softmax(−u) · augmentation 6 แบบ + Cutout มีในโค้ด แต่บทความไม่กล่าวถึงทำตามโค้ดของผู้เขียน
READMEสั่งรัน train.py และ eval.py แต่ทั้งสองไฟล์ไม่มีใน repo (มีเพียง train_dualbranch.py, inference.py)ต้องเขียนลูปประเมินผลเอง

Pipeline หลัก (FF++ → fine-tune CFB → ทดสอบ FF++ และ Celeb-DF) มีโค้ด, config, weight และรายชื่อข้อมูลครบ จึงทำซ้ำได้จริง
